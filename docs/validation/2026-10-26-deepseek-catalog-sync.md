本次物理 POST 共 7 次：初次强制指定工具各一次 HTTP 400，额外一次 Flash 诊断也是 HTTP 400，然后两款各两次成功。没有自动重试未知结果。强制工具选择被当前 DeepSeek thinking 链路拒绝，切换为 Pi 正常使用的 `tool_choice=auto` 后通过。HTTP 400 缺少可信 usage，不能认定没有供应商费用。

这些证据证明真实上游 Responses 协议兼容及合成工具往返，不证明两款模型已经通过实际 Pi SDK、文件工具与中央钱包扣点端到端验收。
