# S2 套餐订单、支付适配与共享点数验证

日期：2026-10-22。分支 `codex/ui-redesign`。本批延续已批准的 Logto 中央账号／共享点数方案，开发微信 Native 和支付宝当面付的订单与验签入账链路，保留自定义接口与旧 v1。商户资料由用户后续通过服务器安全配置接入；本批没有使用真实商户密钥、发起真实收付款或部署公网支付。

## 实现范围

- 独立服务新增不可变报价、订单快照、支付 inbox、交易唯一约束、持久 outbox、租约 fencing、主动查单／关单及未知结果重试。
- 仅已验证的渠道付款事实可以在同一 PostgreSQL 事务授予会员、点数 lot、平衡分录与 outbox。用户不能提交可信价格／wallet／credits，也没有公开标已付、发点、退款或模拟成功接口。
- 微信 RSA-SHA256、平台 serial 信任表、AES-GCM 通知解密；支付宝 RSA2 和原始 JSON business 片段验签。固定官方 HTTPS endpoint，有界请求、响应和超时，禁止重定向与环境代理。
- 退款采用 `unused_full_only`，钱包锁下准入并先冻结，成功通过新增补偿分录和会员撤销处理。部分／已消费／异常退款保留人工核算；旧退款通知不会解除新退款保护，退款先于付款时新 lot 继承冻结。
- 服务器支付配置默认 disabled，显式 loopback test 与 live 分离；测试与正式余额分别统计，S3 订阅执行仍关闭。
- Easel 新增套餐收银台、渠道选择、订单恢复、二维码与期限、退款／待核算状态；私有 bearer 留在 native。服务器 revision 防旧财务响应，财务变化刷新钱包与权益；列表只传元数据，详情单独加载 QR。
- 新增受限 offer-publish／withdraw、payments-work、refund-request／query 和仅 test 模式的模拟管理命令。商户文件与维护步骤见 [支付运维](../../services/platform/PAYMENTS.md)。

## 测试与独立审查

测试使用专属 loopback PostgreSQL 16 数据库，fixture 创建／删除自己的随机 schema 和临时 role。缺少 DSN 会失败，不跳过、不以 SQLite 替代。provider 协议使用临时 RSA/AES 密钥与 HTTPX MockTransport；本地端到端演练使用明显的模拟渠道。

审查先发现并修复：

1. 微信退款同步响应的可选身份字段独立核验；损坏 gzip 转换为稳定不确定结果。
2. 退款后人工核算不应被旧响应隐藏，退款冻结／失败／成功应刷新钱包和权益；支持有效长二维码。
3. 旧退款 A 失败重放不能解冻新退款 B，退款 pending 先于 paid 时不能产生可消费窗口。
4. 订单列表重复 SVG 会超过本机 2 MiB 上限；列表与详情分离，并安全补充同 revision 的派生二维码。

对疑似订单／退款读取不一致的进一步检查证明已有钱包锁可保证投影一致；新增独立连接测试，通过 `pg_blocking_pids` 实际观察写入等待，未无依据更改隔离级别。

## 保留与部署边界

只追加 `005_payments.sql`，不修改已应用的 001–004。预览迁移前对中央业务库与 Logto 库完成私有 `pg_dump`，备份在仓库外 0700 目录、文件 0600 并核对 SHA256。不重新初始化或重启 Logto，不覆盖用户 branding／账号／应用。不改变原项目 `.env`、旧会话或自定义供应商配置。

本地演练不会被标为真实微信／支付宝收款；微信开通 Native、支付宝开通当面付、HTTPS 回调、商户证书／公钥、真实扫码到账、退款和服务器恢复仍需单独验收。当前不支持任意支付网关 endpoint、支付宝证书模式、服务商子商户、部分退款或自动扣费。中央钱包已经具备支付入账与补偿边界，S3 按模型／媒体功能扣点和执行路由尚未开放。

本轮开工的 154 个既有未提交文件均保留；只有 receipt 列明的 15 个文件因 S2 集成而继续修改，没有丢失既有文件。HEAD 与 main 均与开工一致，真实 `.env` SHA256 不变。当前修改未自动提交／推送，未合并主分支。

最终整体验收审阅：[集成审查 PASS](2026-10-22-central-s2-final-review.md)，未发现剩余 P1/P2。记录一个非阻断的报价金额上限差异：可信运营者发布人民币10亿元及以上报价时，核心发布边界和 runtime/provider 上限不同，任务会报稳定错误并重试，不扣款、不发点；正式商业报价需核对渠道上限，后续统一发布前校验。本地模拟报价0.01元不受影响。
