# S3-B 增量文本与中断状态查询验收

日期：2026-10-23。当前分支 `codex/ui-redesign`。本记录将代码与夹具验收、真实供应商验收分开；没有正式商户收款或生产发布结论。

## 已实现范围

- 本机 Codex 代理逐事件转发 SSE，不再缓存整段响应后才展示。保留 256KiB 单事件、8MiB 总量、有界读取／排空／整体期限、一次上游派发、原生零自动重试和终态结算顺序。
- 新增中央只读 `GET /v2/execution-operations`，按 invocation 与 operation 查询已接纳任务；校验当前有效完整 Scope，按历史用户／租户／产品／钱包过滤。只返回公开财务元数据和独立的结果缓存状态。
- 本机记录增加 v2 业务归属摘要、模型和时间。客户端只发现当前账号的私有记录，再使用当前产品凭证查询中央；旧无归属记录不删除、不自动认领。重新登录不会放宽旧任务的续期或执行权限。
- 新增“中断请求状态”手动查询入口。明确区分本机发送／转发进度、中央执行／扣点状态及结果缓存过期。没有自动重发、重新执行工具或把历史结果注入聊天的行为。
- 保留自定义接口、旧版订阅、五套主题和日夜模式；没有改写根 `.env` 或已有 SQL 迁移。

## 独立审查与集成修复

任务审查复现的两个问题已修复并独立关闭：新工作区中间私有目录可能被创建成 0755，导致严格读取器拒绝本机有效记录；早期错误响应首次 drain 失败时可能追加第二条 HTTP 状态行。当前代码以 NOFOLLOW 描述符检查并保护两个私有目录，全部响应在写入前标记已提交。现有祖先目录权限、旧记录字节和时间戳均有保留回归。

整项源码审查另外复现并关闭：恢复查询的第二条请求若返回非 JSON 的 HTTP 401／403／409，旧实现会降为普通 503 并返回第一条成功记录。当前实现先保留 HTTP 认证／账号错误分类，覆盖空响应、损坏 JSON、非对象、异常错误结构、超限、读取中断和截止时间失败；整个读取停止，不返回先前累积记录。错误正文继续脱敏，缺少明确凭证失效错误码时不删除凭证。作者相关客户端组 80 passed／0.61 秒，独立审查新增矩阵 26 passed／0.17 秒，最终完整原生组 461 passed／19.63 秒。整项已实现源码审查最终为 PASS，真实供应商验收仍单独待完成。
