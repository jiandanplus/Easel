## Build configuration boundary

The selected FFmpeg `configure` source at `/private/tmp/easel-ffmpeg-rsa-source-root-receipts-20261028/source-build-inputs/configure` (SHA-256 `5b281b249ad5ad859030b4da0a24ec105b5abff7b3d87a65b302df8bf5fd9833`) has a header-only Vulkan pkg-config check followed by `check_cpp_condition` at lines 7805–7806 and 7849–7850. Therefore a missing `vulkan.pc` alone must not be described as requiring a fabricated pkg-config file. The actual header macro/API compile checks remain to be run. FFmpeg's `glslangValidator` executable shader compiler probe is separate from libplacebo's shaderc/glslang **library backend**; a `glslang-tools` package alone does not prove the libplacebo backend or its features.

Primary project references: [VideoLAN libplacebo](https://code.videolan.org/videolan/libplacebo), [libplacebo build instructions](https://libplacebo.org/), [Khronos Vulkan-Headers](https://github.com/KhronosGroup/Vulkan-Headers), [Ubuntu archive](https://archive.ubuntu.com/ubuntu/).
