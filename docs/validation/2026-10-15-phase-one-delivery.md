## 已实现

### 来源与执行位置契约

- `easel/service_contracts.py` 提供冻结的 `ServiceRoute` 与 `TaskContext`，来源为 custom／subscription，位置为 local／cloud，引擎仍使用既有 runtime。
- 四种组合可以建模；第一阶段只允许 custom/local 执行，未接通组合返回明确错误。
- 旧配置缺字段时按 custom/local 读取，读取过程不写盘；非法持久值拒绝处理。
- 模型、供应商凭证与历史文件不会因读取迁移而重写。

### 设置与任务入口

- `GET /api/settings/harness` 返回 service_source、execution_target 与四种组合的 availability。
- 设置保存兼容旧客户端。未提供新字段时保持当前值，不可用的来源／位置在任何配置写入前拒绝。
- 流式聊天、同步聊天、技能执行、画像增强和 CLI console 采用统一可用性检查。画像任务在创建基线或状态文件前检查。
- 原有“仅聊天”与“具备工具的 Agent”边界保持独立；订阅不是新的引擎 ID。

### 任务快照与会话归属

- 接受任务时捕获来源、位置、引擎和模型选择器，任务记录保存不含凭证的 route 元数据。
- 显式模型、原生默认和 OpenClaw agent 默认分别标记，默认选择器不冒充已解析的上游模型身份。
- 历史绑定缺新字段按 custom/local 解释；更新时保留原生 ID 和其他已有元数据，来源／位置／引擎冲突要求新建会话。
- 现有 API／OpenClaw 历史识别与兼容规则保留。
- 删除会话会清理 Easel 归属与最后任务记录，包括首次执行失败、尚未创建原生历史的会话；不删除外部原生 transcript 或无归属的状态。

### 生命周期修复

- 同步任务由 supervisor 持有工作线程；HTTP 请求断开不提前释放运行中保护，实际结束后写终态。
- 同步任务接受时登记会话归属，直到真实工作结束才释放；期间禁止删除或覆盖同会话，旧回调不会清除新任务的归属。
- 同步执行保持公开文本返回，同时携带结构化结果；非零退出、锁等待失败、超时和异常不再被记录为正常完成，原生任务的停止／失败状态也保留。
- 设置中的聊天模型保存与本地 Agent 启用共享活动任务保护，避免 Easel 在已接受任务期间修改其模型选择。
- Codex 取消或读取失败后，收尾先终结未完成 Future，再退出连接，防止迟到事件产生未回收异常。

## 用户明确延期的真实模型验收

三次隔离原生任务均未产生模型文本、工具调用或目标文件。前两次出现流连接中断；仅为第三次子进程补充现有代理后，观察到 HTTP 401，并在 90 秒外层限制到达时退出。缓存账号识别和模型目录可用不能替代认证推理成功。

用户选择“先完成其余验证，真实模型验证稍后补齐”。后续需要在用户完成正常登录／授权检查后，再分别验证真实模型产物与活动 shell 中断；不得把本阶段模拟网关通过解释为真实订阅服务已经可用。
