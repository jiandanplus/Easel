# 统一媒体网关设置

入口：**设置 → 模型配置 → 统一媒体网关**。这一入口分别控制图片、视频、音乐和配音；原有对话、转写及自定义供应商设置继续保留。

## 在页面中配置

1. 填写网关根地址，例如 `https://gateway.example/proxy`。通常不含 `/v1`，完整保留实际反向代理前缀。
2. 填写普通用户的**业务密钥**。不要填写管理员控制台令牌或供应商后台密钥。
3. 分别将需要使用网关的能力切换为“统一网关”，其余能力保留“自定义接口”。
4. 图片、视频填写网关实际开放的模型名；视频另外选择对应参数映射。音乐选择 DashScope 或 Suno；配音选择实际配置的供应商和模型，必要时填写音色 ID。
5. 点击卡片内的**保存媒体网关**。保存会检查配置合同，下一次媒体任务重新读取配置。

卡片中的“已存配置完整”只表示所需本地字段齐全。保存操作不请求模型，不证明网关已经配置渠道、模型授权、余额或音色审核。真实模型仍需单独验收。页面不会回显已保存的密钥；密码框留空表示保留，提交后清空密码框。

更换已保存的网关根地址时，必须重新填写对应的业务密钥，避免把原密钥误发到另一个服务。清除密钥需要先将四项能力全部切回自定义，再勾选“清除已存网关密钥”并保存。切回自定义本身不会删除网关密钥或原有供应商配置。

## 当前可选协议

| 能力 | 当前设置与路由 |
| --- | --- |
| 图片 | 标准 `/v1/images/generations`、`/v1/images/edits`，以及私有 `/easel/openai/v1/images/variations` |
| 视频 | `/v1/videos`；参数映射为 standard、veo、kling、wan26-t2v、seedance1 |
| 音乐 | DashScope Fun-Music 私有路由，或 Suno native 提交和查询路由 |
| 配音 | MiniMax、DashScope、Fish Audio 私有插件；OpenAI 兼容 `/v1/audio/speech`；Gemini 原生 Generate Content 音频输出 |

这些协议沿用相应适配器的限制，详情见[图片](new-api-image-client.md)、[视频](new-api-video-client.md)、[音乐与私有配音](new-api-media-client.md)和[Gemini TTS](gemini-tts-new-api.md)。统一入口不会使已退役的官方模型恢复服务，也不会自动部署 Fish 私有桥。私有音色需要使用登记和审核流程返回的公共资源 ID。

Gemini 的“自定义配音协议”选项用于保留直连 Generate Content / Interactions 的选择；统一网关的 Gemini 配音固定使用 Generate Content。

已有手工 New API 环境配置会显示“保留旧版 New API”。可继续在下方表格编辑原配置；保存其他能力不会自动迁移这一项。只有明确改选“统一网关”，才需要填写该能力的新模型等字段。统一模式启用时，下方供应商表标记为保留配置，仍可编辑保存，后续切回自定义时使用；旧供应商自测在统一模式下暂停，避免测试到另一条路由。

## 自定义配置与执行环境

新入口将配置保存在独立的 `NEW_API_*` 字段中，四类媒体仅在自己的执行进程内派生实际的 URL、key、provider 和 model。原有 `IMG_*`、`VIDEO_*`、`DASHSCOPE_*`、`MINIMAX_*` 等供应商值不被统一网关覆盖；音乐与配音共享供应商变量时也不会在 Agent 父进程中互相改写。

设置 API 为 `GET/PUT /api/settings/media-gateway`。读取只返回脱敏密钥状态；写入经过合并验证后保存。通用环境配置入口同样验证这些字段，不能绕过模式、密钥和地址规则。真实项目 `.env` 应按本机凭据文件管理。

这是本地媒体配置功能。订阅媒体、云端执行、中央会员／共享额度及供应商账务对账属于后续阶段，仍遵循现有的功能开放状态。
