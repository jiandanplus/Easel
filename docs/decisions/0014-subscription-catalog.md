# 0014 中央统一管理模型，套餐决定权限和倍率（迁移 027）

日期：2026-11-09 · 状态：已实现，待上线；价格由用户之后在后台设置

## 背景
用户要求把桌面端需要的接口统一放到中央后台配置，同时保留桌面的自定义配置；开通订阅的用户直接使用中央接口；套餐可以分别设置可用模型、总点数和倍率，每个模型也能单独设置消耗。

## 决定
**配置放在哪里**
- 供应商密钥和地址继续只放在 New API 管理页和服务器配置文件里，不进入数据库，也不经过后台网页。
- 后台决定：开放哪些模型、每个模型由服务器上的哪个接口提供、网关里的模型名、单价、试用名单和启用状态。

**套餐**
- 套餐可选填 `models`（可用模型清单）和 `pricing`（默认倍率和单个模型的倍率）。不填的旧套餐行为不变。
- 已发布的套餐不可修改，要改就发布新套餐。

**倍率跟着点数批次走**
- 一次调用只用一个价格：按到期先后，取第一组点数够用、且所属套餐允许这个模型的批次，用该批次的倍率。
- 不采用“取用户所有套餐里最便宜的倍率”。否则买一个很小的折扣套餐，就能让其他点数全部打折。

**单价**
- 模型价格写入只追加的 `model_prices`，覆盖定义里的费率，只影响之后的调用。
- 每次调用在开始时把价格快照到任务上，结算只用这个快照。

**新模型必须先真实跑通**
- 后台添加的模型默认不启用，只有试用名单里的钱包能看到。至少有一次结算成功的真实调用后才能正式启用。
- 媒体模型的后台模板必须同时通过服务端和桌面端的校验，由 `test_model_templates_contract.py` 保证。

**无渠道时立刻退回**
- 接口可开启 `preflight_models`：调用前先查网关的免费模型列表，没有这个模型就直接拒绝并退回点数，不再留下“结果不明”的挂起。

**桌面端**
- 自定义配置完全保留，继续由“接口来源”按整个会话在订阅和自定义之间切换。
- 不做“文本走订阅、图片走自定义”这种混用：订阅会话的 Shell 沙箱有意读不到本机 `.env` 密钥，混用要放开这层隔离。
- 订阅的媒体能力只在内置 Pi 中提供；Codex 引擎下脚本会提示切换。

## 影响
- 后台能管理的媒体类型：生图、改图、视频、音乐、语音合成、语音转文字。这些都走网关标准路由。
- 声音复刻不在后台模板里，因为现在的网关没有 `/easel/*` 私有路由，相应适配器在标准 New API 上不能工作。
- 视频、音乐、语音需要服务器配置 `av_tools` 校验生成文件，上线时要一起配置。
- 回滚：027 只新增表和可空字段，旧版代码不读取它们。但旧版 Console 启动检查不认识新增权限，回滚后要先用旧版执行一次 `grant-console`。
