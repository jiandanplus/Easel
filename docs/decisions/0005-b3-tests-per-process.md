# 0005 B3 测试逐文件单独进程运行

日期：2026-11-05 · 状态：已实施

## 背景
B3 目标工厂在状态不明时按设计保留目录与文件描述符，无析构、无释放接口（由 Root 处置）。测试构造数百个此类场景，同进程累积到约 32,000 个描述符，后续使用 `select()` 的用例越过 1024 上限。逐测统计确认其余约 2,400 个测试不改变描述符数。

## 决定
不改动冻结的 B3 语义。CI 中非 B3 测试单进程运行，每个 B3 文件单独一个进程，进程退出即完成处置。B3 回放夹具自行加入 `services/platform/scripts` 到导入路径，不依赖其他测试的运行顺序。

## 影响
带真实 PostgreSQL 的非 B3 单进程运行描述符峰值 13、净变化 0。
