# 0003 应用内更新：离线签名清单 + 受管安装布局

日期：2026-11-05 · 状态：已实施，`desktop-v38` 起生效

## 决定
- 布局：`<根>/v<N>/Easel/Easel.app`，`<根>/current` 指向在用版本；旧版本保留用于回滚。
- 发布清单 `easel-update.json` 用离线 Ed25519 私钥签名，公钥内置；签名用安装包自带的 Node 加密库校验，不新增依赖。
- 安装前依次校验签名、大小与 SHA-256、新包自带的完整文件库存；拒绝明文 HTTP，允许签名后的 `file://`（本机或局域网分发）。
- 切换由新版本的独立进程完成：认证停止旧实例 → 改 `current` → 启动新版本；90 秒内未就绪自动回滚。有任务运行时拒绝更新。
- 默认更新源为本仓库 GitHub 最新 Release，可用 `EASEL_UPDATE_MANIFEST_URL` 改为自有服务器。

## 影响
私钥丢失只能发布内置新公钥的版本并让用户手动安装一次。发布流程见 `packaging/pi/README.md`。
