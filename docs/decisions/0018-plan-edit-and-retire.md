# 0018 套餐可以编辑、复制、停用和恢复（迁移 036）

日期：2026-11-10 · 状态：待上线

## 背景
后台套餐页只能发布，管理员要求能增删改查。套餐发布后不能修改：用户手里的会员资格、兑换码和发放记录都指向具体的套餐编号，改了内容就分不清用户当初拿到的是什么。

## 决定
- **编辑**：表单按原套餐预填，保存时发布同名的新版本（新编号，版本号加一），同一事务里把旧版本停用并记下由哪个新版本替代。已经发给用户的旧版本照常用到期。
- **复制**：按原套餐预填一个新套餐，名称后加“副本”，旧套餐不变。
- **停用**代替删除：停用后不能再发放、不能再生成兑换码、不能再上架售卖价格，桌面端的套餐列表里也不再显示。已经发出去的兑换码仍然可以兑换。随时可以恢复。
- 状态存在新表 `plan_states`，只追加，最新一行就是当前状态；后台角色可读可写，运行时只读。`plans` 表本身仍不可修改。
- 还有在售价格的套餐不能停用或编辑，需要先在“售卖价格”撤回。
- 所有者额度和内部体验额度（编号以 `easel-` 开头）由服务自己管理，页面上只能查看。

## 不做
硬删除套餐；修改已发布套餐的内容；把用户手里的旧版本自动换成新版本。
