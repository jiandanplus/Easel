# 0010 付款关闭期间的所有者额度（迁移 022）

日期：2026-11-06 · 状态：已实施，用户确认“恢复权益”

## 背景
用户账号的内部体验额度（10 点、7 天、只含文本）10-30 到期，余额 0、没有权益，模型目录为空，文本和图片都用不了。`internal-grant` 每个账号只能发一次，付款按用户决定保持关闭，手写 SQL 改账会绕开审计。

## 决定
新增迁移 022 和主机命令 `owner-grant`：
- 固定套餐 `easel-owner-allowance-v1`：100 点、365 天、文本和图片、并发 1、真实点数。金额和时长写死在代码和数据库约束里，命令不接受自定义数量。
- 只有通过 schema owner 校验的主机入口能运行，能力 `owner:grant` 不进入任何通用操作员或 Console 角色，没有 HTTP 入口。runtime 与 Console 对 `owner_grants` 没有权限，启动检查会拒绝。
- 必须提供幂等键、理由和批准依据；记录不可改、不可删。数据库在提交时独立复核套餐、额度批次和发放分录，没有审计记录的同款套餐会被拒绝。
- 同一账号有未到期额度时拒绝再发。

## 影响
- 这不是付款，也不产生收入；点数只是系统内额度，真实费用仍由供应商收取。
- 021 之后追加 022，只新建表、函数和触发器，不改已有数据。
- 将来开放付款后，不再需要这个入口。
