# 0004 按领域拆分 web/app.py

日期：2026-11-05 · 状态：已实施

## 决定
- 领域路由放在 `easel/routes/<领域>.py`，提供 `create_router(core)`；共享路径与执行引擎状态在调用时经 `_core.X` 读取，领域自有的状态与辅助函数随模块迁移。
- `web/app.py` 加载时把自身注册为 `app` 和 `web.app` 两个名字，进程内只有一份实例。
- 测试在 app 模块上替换过的导入名，领域模块也经 `_core` 读取，保证替换生效。
- 字段类型被其他模型引用的 Pydantic 模型放在 `easel/routes/schemas.py`（类定义时就要解析类型，不能经晚绑定的 `_core`）。
- 迁移采用语法树分析：只有全部调用方都在迁移范围、且其他领域模块不经 `_core` 读取的辅助项才随迁。

## 影响
`web/app.py` 从 6,657 行降到 1,913 行。打包前需重新冻结源码清单以纳入 `easel/routes/`。
