# 0015 六类接口都在后台配置，Key 加密保存（迁移 028）

日期：2026-11-09 · 状态：已上线（2026-11-09）

## 背景
用户要求把桌面端设置里的六个分页（对话与脚本、语音转写、配音、生图、视频、音乐）的接口配置全部放进中央后台。决策 0014 里“密钥只放服务器文件和 New API”的做法不满足这个要求，本决策取代 0014 的这一条，其余不变。

## 决定
**页面**
- 后台“接口与模型”页按六类分页，每页有 API 地址、API Key、保存、清除 Key、重新检测，下面是这一类的模型。
- 只有管理员（`providers:manage`）能看和改接口配置，运营者和只读账号看不到。
- 每一类可以配置多个第三方平台，见[决策 0016](0016-console-supplier-platforms.md)。

**Key 的保存方式**
- 后台只有公钥，只能加密，读不回 Key；只有中央服务有私钥（`CENTRAL_PROVIDER_KEY_FILE`，0600）。网页、接口响应和审计里只有 Key 的后 4 位。
- 加密内容里包含分页和地址，改数据库也不能把 Key 发到别的地址。因此修改 API 地址时必须重新填写 Key。
- 配置表只追加，保留谁在什么时候改过。

**生效方式**
- 保存后几秒内自动生效，不用重启。
- 保存的地址和 Key 对这一页的所有模型生效，包括服务器文件里已有的模型。清除 Key 后恢复服务器文件的配置。
- 中央服务保存后用免费的模型列表接口检测一次，之后每 5 分钟一次，结果显示在页面上。
- 一个配置校验不通过时只跳过它并在页面报告，不影响其他分页。

**防止中断调用**
- 这一类还有进行中的调用时，拒绝修改地址或 Key。视频和音乐是异步任务，要用原来的 Key 查结果，中途换掉会让任务卡住。

**协议是固定的**
- 对话走 OpenAI Responses，语音转写和配音走 OpenAI Audio，生图走 Images，视频和音乐走 New API 网关格式。页面上写明要求。

## 影响
- 上线要生成一对密钥：私钥放中央服务，公钥写入后台的 `CENTRAL_CONSOLE_PROVIDER_PUBLIC_KEY`。
- 语音、视频、音乐模型还需要服务器装 ffmpeg 并配置 `av_tools`。
- DeepSeek 等只支持 Chat Completions 的官方接口不能直接填到“对话与脚本”，要经过 New API。
- 回滚：028 只新增表和字段。旧版 Console 启动检查不认识新增权限，回滚后要先用旧版执行一次 `grant-console`。
