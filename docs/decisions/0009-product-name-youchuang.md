# 0009 产品对外名称改为优创

日期：2026-11-06 · 状态：已实施，`desktop-v42` 起生效

## 决定
用户看得到的名称统一为“优创”：工作台界面、App 名称和菜单、图标、登录注册页、助手自称。

内部标识继续用 Easel：Python 包名、`Easel.app` 目录、`~/Applications/Easel`、数据目录、日志目录、`EASEL_*` 环境变量、`X-Easel-Token`、服务器 unit 和数据库名、产品 ID `easel`、仓库名。这些用户看不到，且应用内更新和已安装数据依赖它们。

## 影响
- 2026-11-07 起私有 Console 已改为“优创后台”；2026-11-09 技能说明里助手会转述给用户的文字、命令行工具的标题和提示也改为优创。技能来源记录（`EASEL-META.md`）、脚本内部说明和开发文档仍写 Easel，它们记录的是仓库与项目来源，用户看不到。
- Finder 里的 App 文件仍叫 `Easel.app`，系统语言为中文时显示本地化名称；旧版本的目录保留 Easel 名称。
