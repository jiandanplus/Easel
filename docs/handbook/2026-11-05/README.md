## 使用约定

1. **日期与版本决定适用范围。** 历史 README、验证记录和发布回执保留原时点内容。本文引用的生产拓扑来自已保存的部署记录，编写时没有通过 SSH 重新核验服务器。
2. **区分五种状态。** 源码存在、合成测试、实际隔离验证、生产部署、正式发行分别记录。构建成功不代表用户已升级，健康检查成功不代表模型、扣点或支付成功。
3. **操作步骤不是自动授权。** 本次只整理文档，没有执行服务维护、数据库迁移、模型调用、扣点、付款、Git 提交／合并／推送。后续执行以当次维护目标和具体计划为准。
4. **文档不承载凭据。** IP、域名、服务名可用于定位；密码、Key、令牌、DSN、Cookie、原始备份和用户内容仅放受保护配置或受限数据库。示例中的 `REPLACE`、`YOUR_*`、`/ABS/...` 均为占位项。
5. **命令位置要一致。** 本手册本机终端示例使用 `rtk proxy`；SSH 引号内是远端命令，不假定服务器安装 RTK。仓库命令默认从 `/Users/jiandan/Code/GitCode/Easel` 执行。未来换电脑时使用实际检出目录。
