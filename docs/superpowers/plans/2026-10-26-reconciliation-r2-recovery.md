# R2 核算恢复实施计划

**Goal:** 修复待核算占满后无法恢复的缺口，支持可信终态恢复及明确批准的运营承担路径。

**Architecture:** ExecutionService 保持冻结费率/资金事务；独立证据模块先保存可信终态，独立核算模块提供只读计划及受控幂等处置。Console 不获得资金写权限。

**Tech Stack:** 现有异步 Python、PostgreSQL、FastAPI 与 React/TypeScript。

**阶段状态：** R2 代码、追加迁移及桌面兼容版本已经发布。中央全量真实隔离 PG 回归 1101 项通过；中央实际 release 为 `/srv/easel/releases/20261026-reconciliation-r2-v1`，17868 工作台为 Pi portable v17。代码切换财务写入为零，原三笔预留及八表全钱包投影完整保持。之后仅对明确批准的三笔真实执行平台承担，释放 29184 微点，待核算/在途均清零；完整差异、原键查询、独立只读后验和处置后加密备份通过。本人登录原钱包后的 Pi／Flash 文件工具对话与扣点已真实通过，三轮正常模型请求收费共 2280 微点，最终余额 9.971423 点，重复 GET 未新增派发或财务变化。详细证据见 [R2 验证记录](../../validation/2026-10-26-reconciliation-r2-recovery.md)。

## 约束

- 当前分支开发，不合并；自定义/订阅、账号、历史、旧账完整保留。
- 不使用估算 usage、零费用假回执、提高上限或重发来绕过待核算。
- 真实运营承担在精确 plan 与确认之后执行。
