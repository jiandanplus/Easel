### Stage contract

- Canonical absolute existing stage root basename run-av-pack-<nonce32lowerhex>. Its exact entries are stage.json, code/, inputs/, host/, results/. All directories owned effective UID/GID, mode0700, full-component nofollow (canonical /private paths on macOS; /tmp symlink is not silently followed). Directory identity dev/ino/mode/uid/gid stable; do not require parent nlink/mtime/ctime unchanged when legitimate results are later written.
- The owner/mode0700 rule applies to the stage root and its four child directories, not system ancestors such as / or /private/tmp. Ancestors are traversed nofollow. Test fixtures may explicitly create their stage under the canonical resolved pytest temporary parent; preparation itself never resolves an untrusted symlink.
- stage.json <=16384, owned0600 regular singlelink, stable full file identity before/after read and current path, exact caller expected SHA256, strict duplicate-free/nonfinite-free/canonical JSON. Exact descriptor keys: format='av-pack-host-stage-v1', nonce, profile_sha256, code_sha256, host_sha256. code_sha256 exact four worker CODE_NAMES. host_sha256 exact pack_profile.py, pack_artifact.py, pack_http.py, pack_api.py. All hash values nonzero lowercase64hex. nonce matches stage basename and profile.
- code/ exact four names pack_worker.py/pack_runtime.py/pack_store.py/git_objects.py; host/ exact four above. Each owned0600 regular singlelink, <=262144, full nofollow/identity/size/hash before and after. Verify ALL eight raw files and descriptor/profile/input pins BEFORE first helper compile/exec. Include staged pack_profile.py pin in descriptor; Root bootstrap authenticates the callable from those approved bytes separately. No executing staged pack_profile again recursively.
- inputs/ exactly profile.json for nondecode, profile.json+source.pack fordecode. profile <=16384 with descriptor hash and canonical form. After all sources pinned, compile retained pack_worker bytes under a private SHA-derived module name, call its actual parse_profile/validate_profile, require all4 profile code pins exactly descriptor code pins, exact uid/gid equal stage owners, nonce same. The parser/protected loader/verifier rules are not duplicated or weakened.
- To avoid a dependency cycle, first parse the hash-bound profile with a bounded generic strict JSON reader (without executing helpers) and read only the declared mode/pack file-size-SHA facts needed to check inputs. Enforce their primitive types, fixed basename and size/hash caps before using them. After all source and input hashes pass, the actual pinned worker parser remains the authoritative complete profile schema validator. Hash/metadata faults must reject before any compile; a deliberately re-pinned semantically invalid profile may reach the trusted worker parser, but never source decoding/main/native operations. Do not claim complete profile schema validation happened before worker compilation.
- Decode source.pack size32..67108864 and exact profile size/SHA. Stream hash in <=65536 reads, no full pack allocation or decode. Check regular0600/singlelink/ownership/current identity and EOF. Host source preparation is not object-integrity verification. Tests only tiny synthetic bytes, never actual candidate paths.
- results/ identity checked, contents not read by this helper. - Read/recheck same directory listings and current absolute directory identities at the end to catch swaps/extra files. No symlink/hardlink/path traversal/FIFO/owner/mode/size/drift acceptance; no path extraction. Each owned fd close attempted on every failure, fixed safe StageError without raw path/exception text. Failed preparation exposes no partially prepared module/result.
- After all eight pins validated, load retained worker, artifact, HTTP and API modules; register needed SHA-derived sys.modules names for dataclasses. worker.prepare_runtime(profile, code_dir=verified code directory) must run and retain that same runtime validator. Its four re-read bytes must equal the already verified bytes. Do not host-execute pack_store/git_objects or any decode/main/native operation. Return same prepared worker.validate_report, artifact functions, HTTP module and API module for later controller wiring.
- recheck_stage has mandatory callable guard, invoked before/after bounded reads including EOF and at final current-path/identity checks. Reverify all original descriptor/profile/code/input bytes and original identities; no execution/module reload. Exceptions/deadline failure reject.
