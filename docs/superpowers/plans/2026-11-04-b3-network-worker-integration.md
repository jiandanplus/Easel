# B3 N4 implementation breakdown

Scope is the approved inactive-default-interface amendment. This is an implementation breakdown, not new operational authorization. Current branch stays `codex/ui-redesign`; original failed containers and all source data remain unchanged. Root alone performs native operations after source review. Source tests and fixture hashes do not prove live isolation or a restore.

## N4a — fixed native observation reader

Add `network_reader.py` and its focused fake-primitive tests. The only production entrypoint is `observe_worker_network(deadline_ns: int) -> NetworkObservation`. It has no selector, caller paths, expected data, callbacks or policy inputs. Imports perform no I/O. It uses the existing N2 transport unmodified, then the existing pure N3 validator is called by the worker in the next task. Reader output is data only.

The reader brackets one complete six-dump N2 pass with fresh namespace, sysfs and proc reads from its own process, and preserves the caller's original deadline. Capture kernel release from `os.uname().release` and byte order from `sys.byteorder`; no subprocess/platform discovery fallback. Fixed paths are `/proc/self/ns/net`, `/sys/class/net`, `/proc/net/dev`, `/proc/net/if_inet6`, `/proc/net/route`, `/proc/net/ipv6_route` and `/proc/net/fib_trie`. Each proc file is at most 65,536 bytes. Interface scalar files are at most 128 bytes each and only `ifindex`, `iflink`, `type`, `flags`, `operstate`, `address` are read. Entries must be the exact ten source-profile names plus `bonding_masters`; unknown names fail before constructing a child path. Root-owned regular control metadata is observed via stat, not inferred from the filename.

Descriptor custody: open fixed kernel roots and directories with CLOEXEC and DIRECTORY where appropriate, retain each original descriptor until its work is finished, and close owned descriptors on every terminal branch. Use anchored directory FDs for child access; do not accept a caller FD or follow an arbitrary symlink. Explicit kernel exceptions are `/proc/self/ns/net`, `/proc/net` resolving the current process network directory, and exact `/sys/class/net/<known-name>` symlinks resolving to `../../devices/virtual/net/<same-name>`. Verify the actual class entry and resolved kernel directory refer to the same device/inode and directory type; verify root ownership, immutable ancestry semantics and before/after metadata around use. Reject a changed target, an unexpected link text, non-directory target, control symlink or an alternate device path. The control remains a nofollow regular root-owned 0644 attribute. No filesystem writes, namespace changes, interface changes, privileges or external connections.

The root-owned directory constraint above applies to sysfs ancestry. The fixed `/proc/self/net` directory may belong to the current process UID/GID; verify its directory type and held-descriptor identity without assuming it belongs to root. Its fixed procfs origin remains part of the future host/image/mount qualification, not authority created by these stat fields.

Use ASCII-only closed scalar grammar: canonical nonnegative decimal with a final LF for indexes/types, `0x` lowercase hex flags with final LF, lowercase colon-delimited current address bytes, and lowercase alphabetic operstate with final LF. Parse within bounds, never strip arbitrary whitespace/control characters. The pure N3 validator decides all profile semantics after acquisition. All failures are generic `B3Error` without raw payloads or chained exception text. A BaseException must still attempt descriptor cleanup and propagate; any failed cleanup forbids positive return. There is no retry of a failed native read, dump or whole observation. Deadline checks surround each native operation, including cleanup; an expired interval must not skip close. Two sequential observations do not claim atomicity.

Tests must use a complete otherwise-valid fake kernel tree and existing full same-namespace fixture as data. Observe exact path/flag/dir_fd/read cap and call ordering, all descriptor cleanup on each injected boundary, partial reads within caps, empty/oversize/invalid scalar bytes, wrong root/control/interface type or ownership, symlink text/identity drift, unknown names before path access, before/after namespace and sysfs data retention, N2 failure/no retry, original deadline exhaustion, and no I/O at import. No native socket, Docker, DB or real kernel read in agent tests.

## N4b — v3 contract and worker integration

After N4a review, freeze a task-specific v3 schema before source edits. Preserve original request/policy/manifest binding and generic errors. Add the source-fixed profile hash and an independently acquired expected security snapshot hash to the host policy. These are plain data; the future host owner must derive the expected snapshot from a separate fixed observer bound to its original owned target, never by adopting the worker's report or echoing a supplied result. The wire must reject v2 positive reinterpretation.

Transmit two full observations acquired before and after installed-origin hashing. Closed wire adapters preserve all original raw datagrams and proc/sysfs bytes; on both encode and host validation, independently reparse through N1/N3 rather than trusting cached messages, supplied result objects or snapshot fields. Derive truthful complete observed/active inventories, control metadata, full canonical security snapshot, raw hashes and telemetry from these observations. Both security snapshots must match each other and the original host-policy pin. The profile hash must equal the frozen source-owned profile. Excluded counters may differ and remain in raw evidence. Root retains original process/container/image and both namespace proofs separately; no deserialization creates execution authority.

Replace the old raw `sysfs == [lo]` gate and loose IPv6 route parsing with N4a/N3. Preserve UID/GID/capabilities/NNP/cgroup resource checks and all installed-file/import-origin checks. Compare stable security metadata, not raw counter-bearing routes. Before writing a v3 response, set the original stdout descriptor nonblocking; retain one deadline and byte offset through EINTR, EAGAIN, partial writes, full pipe, broken pipe and deadline expiry. No large blocking write after readiness. Static best-effort stderr failure handling stays bounded.
