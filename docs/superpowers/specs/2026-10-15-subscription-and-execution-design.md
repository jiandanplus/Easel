# Easel 订阅、自定义服务与本机／云端执行设计

日期：2026-10-15

状态：用户已确认产品方向；本文记录总体架构与交付边界，不代表功能已实现。

## 1. 已确认的目标

- 用户下载发行包后，无需单独安装 Agent CLI，即可使用默认内置执行引擎。
- 支持订阅服务：注册、登录 Easel，开通套餐后直接使用套餐包含的接口，无需自行填写供应商凭证。
- 保留自定义服务：使用用户自己的接口、模型服务或兼容的本地模型。
- 支持本机与云端两种执行位置，由用户按任务选择。
- 保留现有画像、技能、内容产物和外部执行引擎接入能力。

以下为达到这些目标的工程设计，不将尚未交付的能力显示为可用服务。

## 2. 当前项目的实际接入点

当前没有完整的平台注册、订阅、支付、用量账本和多租户云端任务系统。社媒账号登录与 Easel 平台账号分开建模。

## 3. 三个独立维度

### 3.1 模型服务来源

- `custom`：用户自己配置的服务。
- `subscription`：Easel 账号获得的套餐服务。

模型来源描述由谁提供服务、认证和承担模型费用，不决定任务在哪里执行。

### 3.2 执行位置

- `local`：文件操作、命令和技能脚本在运行 Easel 本地后端的设备上执行。
- `cloud`：工具和技能在云端隔离工作区中执行。

本机执行也可能把任务上下文发送到云端模型。“本机执行”不作为“离线处理”的承诺。

### 3.3 执行引擎

继续使用现有引擎适配层。默认内置引擎在协议兼容性验证后确定；现有 Codex、OpenCode、OpenClaw、通用 ACP 接入保留为高级能力。

仅聊天是任务能力边界。模型订阅不自动赋予直连聊天本地工具能力。

## 4. 四种组合

| 来源 | 位置 | 身份与资源 |
| --- | --- | --- |
| custom | local | 可不登录 Easel；模型使用用户自己的服务，本机资源由用户提供 |
| subscription | local | 需要平台登录与有效权益；模型使用套餐，本机执行工具 |
| custom | cloud | 需要平台账号与云端执行权益；模型费用与云端资源分别核算 |
| subscription | cloud | 需要平台账号、模型权益与云端执行权益 |

自定义云端执行的支持范围由实际可达性决定。用户电脑上的 localhost 地址不能被云端直接调用；首版对这类目标拒绝提交并说明原因，不默认建立隧道。

## 5. 客户端产品行为

### 账号与订阅

显示平台登录状态、套餐、权益周期、各项额度、用量明细和订阅管理入口。与公众号、B 站等平台连接页面分开。

### 模型服务

订阅与自定义两套设置分别保留。订阅模式从服务端获得真实模型目录与能力，不要求输入上游供应商 Key；自定义模式保留地址、模型、凭证与连接测试。

对话、转录、配音、生图、视频、音乐按能力接入，某通道只有后端已交付且套餐授权时才可用。首版可以只开放已验证的对话通道。

### 任务执行

设置中保存默认执行位置，发起任务时允许覆盖。提交前展示执行位置、所需素材上传与资源类别。需要本机应用、社媒浏览器会话或其他本机专属资源的任务，首版仅支持本机。

只展示已经部署、健康检查通过并有相应权限的执行能力。未交付的云端执行不能通过按钮触发本机兜底。

### 切换与历史

每个任务创建时固定来源、执行位置、引擎、模型、工作区、能力清单和计费规则版本。运行中不切换来源或执行位置。现有原生会话保持原引擎归属；新默认值只作用于新任务或新会话。

订阅到期、额度不足、凭证失效时说明原因；不自动改用用户自定义凭证，也不从自定义服务静默切到付费套餐。

## 6. 云端服务边界

### 身份与权益

账号服务维护用户、设备会话、登录撤销与访问凭证。套餐服务返回可用模型、能力、用量周期、并发和云端资源权益。服务端是权益判断的权威来源。

### 模型网关

客户端与执行器使用 Easel 用户或任务范围凭证。网关鉴权、检查额度、选择兼容上游并转发流式请求。上游平台总凭证只留在云端服务，不放进客户端发行包。

默认内置引擎必须验证请求协议、认证刷新、工具调用、流式事件、上下文处理和取消行为。当前 Codex 自定义供应商采用 Responses 协议；不能把仅支持 Chat Completions 的网关视为已兼容 Codex。

自定义本机请求直接使用用户配置，不为了统计而强制转发平台网关。自定义云端任务所需凭证以任务范围交付给隔离执行环境，不写入日志、产物和可下载的任务描述；任务结束撤销临时授权或清理临时副本。

### 用量账本

模型消耗、云端执行与存储分别记录，可由套餐组合展示。文本按模型实际用量核算；图片、音视频和执行资源按各自计量规则核算。规则带版本，任务保留创建时规则。

提交／调用先预占预算，再按实际已产生的消耗核销，释放未使用部分。重复支付通知、客户端重试与事件重放不得重复入账。取消、超时或模型失败也可能已经产生上游费用，按实际可核验消耗结算，不承诺一律零扣费。

多步骤 Agent 任务中的每次模型调用都进入账本。服务端限制预算和并发，不仅在客户端显示剩余额度。

### 支付与订阅状态

支付结果由服务端验证，不能以客户端的支付成功页面作为开通依据。订单、事件和权益变更使用幂等标识，保留可核对记录。

本文不确定套餐金额、支付渠道、自动续费政策或商业供应商；这些属于相应子项目上线前的产品与运营输入，不影响来源／执行位置的基础契约。

## 7. 统一任务与云端执行

任务描述至少包含：task_id、owner_id、服务来源、执行位置、引擎、模型、能力清单、工作区引用、输入文件引用、预算规则版本与幂等键。可持久化的描述不包含原始密钥。

本机和云端执行器共用任务与事件结构，复用技能和引擎适配器；通过工作区准备器转换真实路径，不假定能迁移正在运行的引擎原生进程。

云端链路由任务 API、持久化队列、调度器、隔离执行环境、产物存储与事件存储组成。执行工作区按用户和任务隔离，资源配额独立。控制面不直接在自身宿主机执行不受隔离的用户命令。

任务状态：queued → preparing → running；running 可进入 waiting_for_user，继续后返回 running；终态为 succeeded、failed 或 cancelled。取消请求使用 cancelling 过渡，直到执行器确认停止；失联任务进入 recovering，由调度器核对执行状态，不直接重复执行有外部影响的步骤。

关闭客户端不取消云端任务。需要授权时任务暂停，重连后可查看请求；等待授权不保证任务自行完成。事件带递增序号，重连按游标补读；取消和审批均验证任务所有者。

首版只上传用户为任务选择的素材及必要工作区文件。任务结束可以下载产物并按平台保留策略清理。社媒登录态、完整本机目录和用户全部历史不随云端任务默认上传。

## 8. 内置运行时与发行包

完整发行包包含后端运行环境、预构建前端、技能资源、默认引擎及声明支持功能需要的工具。无需用户手动安装 Python、Node.js 或 Agent CLI；允许高级用户显式选择系统安装的外部引擎。

程序资源与可写用户数据分离。统一解析引擎路径，安装检测、模型查询、实际任务使用同一结果。固定经过兼容性验证的运行时版本，保留发行清单和许可证信息。

按操作系统和架构构建，在未安装开发工具与 Agent CLI 的干净环境中验证启动、登录、自定义调用、技能任务与升级后数据保留。源码下载与应用发行包分别说明。

## 9. 交付顺序与验收

1. 来源／位置／引擎边界与兼容性验证：旧配置和会话可继续使用，协议验证有真实结果。
2. 默认内置运行时与自定义本机闭环：干净设备下载、启动、配置自己的模型并完成带产物任务。
3. 平台账号、模型网关、权益和用量：测试账号取得真实授权，可完成任务、查看用量，超额会被服务端拒绝。
4. 订单与订阅闭环：沙箱支付可验证开通、重复通知、到期和异常恢复。
5. 云端执行：按任务选择本机／云端，断开客户端任务继续；重连补读、审批、取消、文件隔离和产物下载通过验证。
6. 逐能力接入媒体接口，发布多平台发行包。

每个子项目在编码前形成自己的详细设计和实施计划。当前 UI 设计分支中的日夜模式修改独立保留，不以本设计确认替代它的验证或提交。

## 10. 验收重点

- 四种组合的权限与可达性判断正确，非账户用户不能调用平台云资源。
- 未提供订阅后端时不显示已开通、虚构余额或成功调用结果。
- 新模式不会覆盖用户的自定义凭证，不会迁移旧原生会话或静默改换付费来源。
- 同一任务重试、重复支付事件、并发额度争用可核对且不会重复扣费。
- 云端关闭客户端后继续执行；权限请求可恢复；取消后执行器实际停止。
- 云端任务只能访问自己的工作区与允许的服务，私有凭证不进入日志和产物。
- 订阅中声明支持的每个媒体通道均有真实端到端结果。
- 发行包在无单独引擎和开发环境的设备上完成真实任务。
