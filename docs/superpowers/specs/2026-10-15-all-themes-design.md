# Easel B–E 主题实现

用户已确认 A 版实机并授权继续其余四个已批准的设计方向，参考 design/UI-v2-20261015/{B,C,D,E}/01.png 至 22.png。

- A (`paper`) 保持无偏好、非法值与旧 light/dark 的默认回退，不改变现有 A 版。
- B 极简效率台 (`minimal`): 冷白、石墨与钴蓝，无衬线字体、清晰边框、紧凑效率布局，工作台创作入口在统计前。
- C 深色创作舱 (`forest`): 深绿黑与薄荷绿，山林背景、分层暗色卡片；浏览器原生表单使用 dark color-scheme，按钮文字和状态对比清楚。
- D 柔和彩色工作室 (`pastel`): 奶油底、鼠尾草绿、淡紫与杏色，柔和插画、宽松圆角与多色统计；桌面工作台将创作入口与统计并列。
- E 瑞士网格系统 (`swiss`): 米白、黑色、信号橙，大号粗体标题、直角、清晰线框、紧凑网格，工作台问候与统计横向编排。
- 五套覆盖全部现有页面、设置通道、输入/禁用/悬停/焦点/选中、抽屉、向导、错误与空态，复用真实数据和既有业务逻辑。
- 主题页全部开放、预览各自对应风格，准确标明当前选中与默认。保存与启动前应用支持五种 id，切换不卸载当前页面或草稿。存储不可用仍能本次切换，跨标签同步正确。
- 继续使用本地字体与打包资产、相对资源路径；不增加远端字体依赖、不创建演示业务数据、不修改权限/账号/发布后端。
- 测试主题持久化、默认与旧值回退、非法值拒绝、light/dark color-scheme、跨标签切换、before-paint 一致性。真实浏览器检查四套所有主页面、主题/模型/环境/更多设置、抽屉和窄屏。
