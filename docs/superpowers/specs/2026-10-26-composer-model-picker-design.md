# 对话输入框模型与推理强度选择

用户指定：输入框右下增加参考图中的模型菜单，直接加载当前渠道可用模型，按接口能力开放推理档位。继续当前 UI 分支，保留订阅及自定义接口、真实账号和历史。

采用独立的对话级选择器。工具栏显示模型名称和可选档位，弹层分为模型列表与推理强度，支持搜索、刷新、键盘关闭和窄屏滚动。选择影响下一次请求；正在执行的任务冻结参数。设置中的模型继续作为默认值，不写回全局配置。

后端统一提供 `GET /api/chat/models`：`revision`、`ready`、`switchable`、当前来源/引擎、默认模型及安全的模型列表。订阅目录来自已登录中央账号；自定义 Pi/API 从服务器保存的接口读取目录，Key 不进浏览器。不支持安全对话级切换的旧引擎保留默认运行并说明原因。失败或身份/渠道变化后不能把旧目录当当前可用目录。

每轮显式选择携带 `model`、`catalog_revision` 及可选 `reasoning_effort`。服务端校验目录时效、渠道和身份、模型成员资格及档位，然后创建不可变任务上下文。中央仍独立授权模型和计算费用；客户端不能提供费率、钱包或身份。断线恢复读取原任务，不重发新选择。

能力仅来自当前接口明确提供的 `reasoning: {efforts: [...]}`（自定义目录也可提供 `supported_reasoning_efforts`）。允许 minimal/low/medium/high/xhigh/max；空列表表示不支持，缺失表示未知。未知时使用默认且不发送显式推理参数，不按模型名猜测。中央定义新增可选字段并在预留点数之前校验显式档位；旧部署没有该字段时不开放选择。

Pi SDK 保持锁定 1.4.0。worker 将已校验的档位映射到 thinkingLevel 和 Responses 参数；默认档位省略推理参数。Pi 私有历史允许同供应商/同账号范围内换模型，其他所有归属校验保持；不复制其他账号历史，不丢弃或重置对话。

验证分为前后端行为测试、实际 SDK 到本机合成接口的报文验证、独立中央隔离测试、打包清单校验、原 17868 浏览器验收。真实账号不退出，不创建真实模型请求、付款或扣点。中央服务能力代码与本机包分别报告部署状态。
