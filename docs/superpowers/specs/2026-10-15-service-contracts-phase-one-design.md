# 第一阶段：服务来源、执行位置与会话归属契约

日期：2026-10-15。用户已授权在 `codex/ui-redesign` 开发与验证，不合并主分支。

依据：[总体设计](2026-10-15-subscription-and-execution-design.md) 与 [交付路线图](../plans/2026-10-15-subscription-and-execution-roadmap.md)。

## 交付范围

本阶段实现来源与执行位置的后端契约、旧配置兼容、会话绑定和任务上下文，并验证候选默认引擎。订阅服务、云端调度、支付和发行包属于后续阶段，本阶段拒绝实际调用未接通的服务。

来源使用 `service_source=custom|subscription`，执行位置使用 `execution_target=local|cloud`，引擎继续使用原有 `runtime`。不将来源添加到引擎枚举。

## 配置与可用性

- 在现有引擎配置中增加上述两个字段，缺省按 `custom` 和 `local` 解释。
- 读取旧配置不写盘，不修改 `.env`、供应商凭证、模型映射和原生历史。
- 非法持久化字段产生明确错误；不得把损坏数据当成默认值。
- 设置响应返回当前来源、位置和可用性描述。第一阶段仅 custom/local 可用，其他选项带不可用原因。
- 设置保存支持新增字段，旧客户端未提交字段时保持当前值。不能把 subscription/cloud 写成活动模式；请求应返回冲突并且不修改任何配置。
- 新的通道切换仍使用原有运行中任务保护与环境锁。对原有设置接口保持向后兼容。

## 不可变执行上下文

使用小型、不可变且不含密钥的类型描述来源、执行位置、引擎、模型与任务能力。所有枚举严格校验。

在提交任务时解析和检查来源／执行位置；不可用组合在读附件、启动进程、向上游请求或写任务记录前拒绝。任务中途不能因默认设置变动改变来源、位置、引擎或选定模型。

仅聊天能力与工具能力分开描述；平台服务尚未接通时不宣称订阅能力已经可用。新增任务记录保留脱敏路由上下文，便于后续账本与执行器接入。

模型快照记录 Easel 实际提交的选择器。显式模型标记为 explicit，原生默认标记为 native-default，OpenClaw 的 `openclaw/default` 标记为 gateway-agent-default。后两者不冒充已解析的上游模型身份；引擎外部配置的修改不受 Easel 控制。Easel 自身修改活动聊天模型的入口须在任务已接受或运行时拒绝写入。

## 会话绑定

- 原有只包含 runtime/native_id 的绑定按 custom/local 解释。
- 原有模型 API 历史、OpenClaw 历史和传输绑定的归属检测继续有效；本阶段不迁移其历史。
- 写入／更新绑定时保留已有字段与原生 ID；禁止以新绑定替换原生历史。
- 绑定后不能静默变换来源、位置或引擎；需要变化时新建会话。
- 模型快照属于单个任务，不增加“整段会话永远不能换模型”的限制。

## 接入与文件职责

- 新的独立服务契约模块负责字段校验、可用性和不可变上下文，避免将全部逻辑放入 `web/app.py`。
- `easel/harnesses/store.py` 负责旧配置读取与持久绑定。
- `web/app.py` 在设置与任务入口调用契约，保留现有三类执行通道。
- `web/frontend/src/lib/api.ts` 补齐响应与请求类型；本阶段不改动主题和日夜模式文件。
- 引擎验证脚本只使用临时工作区和当前授权的少量模型调用，不修改全局凭证或其他会话。

## 验证与证据

先写失败测试，再实现契约与接入。覆盖四种枚举组合、非法输入、无写盘迁移、设置保存原子性、运行中保护、旧会话、来源／位置不符拒绝以及任务上下文固定。

协议模拟测试与真实模型验证分别记录。真实验证至少检查当前可用引擎的启动、认证、流式事件、工具调用与文件产物；中断和权限优先使用可控协议测试，不影响其他原生进程。

内置引擎选择记录精确版本、可打包资源、协议和认证约束，以及尚未被真实验证的内容。现有模型任务成功不能当作未来订阅网关已兼容的证据。

## 本阶段验收

1. 旧配置读出的来源／位置正确，读取不改动任何文件。
2. 原有模型和引擎路径继续工作，历史绑定不会被新设置覆盖。
3. subscription/cloud 请求被明确拒绝，且没有产生本机或上游执行副作用。
4. 新任务具有不可变、不含凭证的上下文，结果记录可关联其路由。
5. 自动测试、前端类型构建、代码审查和真实引擎证据分别提供结果。
6. 变更只提交当前分支；既有未提交 UI 修改不夹带到本次提交。
