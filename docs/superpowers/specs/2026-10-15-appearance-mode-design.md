# 日间、夜间与跟随系统

用户指定：在左下角本地运行区域添加日夜切换按钮；日间使用 A，夜间使用 C；设置中提供跟随系统，且默认为跟随系统。

- 默认模式为 system，以 prefers-color-scheme 实时选择 paper / forest。旧的 easel_theme 值不妨碍本次默认跟随系统；新的外观偏好保存到 easel_appearance。
- 设置增加跟随系统、日间模式、夜间模式三个按钮。手动日夜选择固定对应 A/C，不再受系统变化影响。
- 左下角显示当前日夜图标，点击切换到相反模式并保存。窄屏保留图标和可访问名称。
- 保留五套主题卡片；点击卡片进入 custom 状态，明确提示已暂停自动跟随，直到重新选择上方模式。
- 偏好原子保存为 {mode, theme}，跨标签同步；首次绘制与运行时使用相同规则，避免深浅闪烁。存储或 matchMedia 不可用时界面仍可使用。
- 系统监听始终更新当前系统状态，仅在 system 模式下改变外观；卸载时释放监听。
- 验证默认系统深浅、实时变化、手动覆盖、五主题、刷新、跨标签、清除存储、阻止存储、无系统 API、监听清理、桌面与窄屏。
