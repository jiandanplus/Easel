# Codex 风格工作台分栏

状态：用户直接要求采用左工具栏、独立对话列表、右内容区，本次按此明确结构执行。

桌面从左到右排列三个同级区域：80px 工具栏、264px 对话列表、剩余宽度的现有内容区。工具栏使用图标与短标签，保留全部页面入口，导航独立滚动；账号、运行状态与日夜切换固定在底部。对话列表仅在对话页且设置未打开时显示，与工具栏全高并排，标题/新建固定，列表独立滚动。右侧聊天、素材、输入、流式生命周期和其它内容页面沿用现有实现。

新建 `ConversationSidebar.tsx`，接收原会话数据与操作回调；原 `Sidebar.tsx` 仅保留全局工具和账号。App 将两个侧栏与 main 排为同级元素。使用最后导入的 `workspace-layout.css` 和现有主题变量统一五套主题的结构，避免旧 `.sidebar-section` 垂直布局与断点影响。760px以下对话列表改为可关闭的抽屉，工具栏提供“对话历史”按钮；关闭或Escape后焦点返回入口，桌面不将列表排到工具栏下方。

保留自定义接口/订阅、所有真实账号/会话/配置/点数。只改前端布局，不发真实模型请求，不更改登录权限，不合并主分支。源码与本地可视预览分别验收，不把旧打包应用的界面当作新源码的显示结果。
