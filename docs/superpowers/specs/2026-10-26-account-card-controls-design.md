# 用户卡片收纳运行状态与显示模式

用户已授权自行设计并直接修改。沿用当前 `codex/ui-redesign` 与原工作台，不另行等待设计确认，不合并主分支。

侧栏底部仅保留头像。用户卡片按账号头部、账号与订阅/设置、本地偏好、退出登录排列。本地偏好采用两行：运行状态点和“本地运行”，右侧显示当前 Agent；“显示模式”右侧复用日夜切换按钮。控制区独立于账号状态分支，登录进行中、入口未配置及状态异常也可显示。

保持原状态详情与就绪判断、未登录点击直接发起登录、账号请求状态机、设置内容、日间 A/夜间 C 与设置中跟随系统逻辑。新区域使用自己的 CSS 作用域，避免窄侧栏样式隐藏文字；沿用现有主题变量、键盘焦点和短视口滚动。

验收包括现有账号/主题/三栏回归、前端构建及 lint，原工作台卡片位置与按钮实际交互。更新应用资源时保留原 HOME/workspace、登录、历史和自定义接口配置，不调用模型，不修改中央服务或账本。
