# Easel UI 设计精修 v2

本次在 `codex/ui-redesign` 分支目录中交付五套完整视觉方案，每套 22 个独立页面，共 110 张 PNG。109 张图片为原生 1586 × 992，E13 为原生 1585 × 992；没有通过插值放大来宣称 4K。

打开 `index.html` 即可离线查看；也可访问当前本机预览 http://127.0.0.1:54598/。左栏选择页面，上方切换方案。并排比较展示同一页面的五个方向，点击图片可放大，再选择原生尺寸。

## 文件与核对

每套的 `01.png`—`22.png` 是最终图片；相同编号的 `-prompt.txt` 是生成提示词，`.json` 记录原生成路径与视觉核对，`.ocr.json` 保留文字识别证据。定向修正提示词另存为 `-correction-prompt.txt`。`spec.json` 保存准确文案清单；`manifest.json` 保存 110 张图的 SHA256，`checks.json` 保存最终验收范围。

已核对核心标题、按钮、分类和相应选中状态，OCR 漏识别项用人工视觉确认补充。发现的搜索框遗漏、发布前预检遗漏、账号与扫码状态矛盾、沙箱与授权控件混用等已用图像生成定向修正。

这些图片是视觉评审稿。部分辅助说明、缩略图文字、示例日期与模型标识由生成器补充，未声称所有细文逐字无误；A04 的非核心示例日期显示为 2024。界面落地时按项目真实字段、状态和字体排版。原有 v1 图和生成原图保留。当前交付为设计资源，应用源码未修改。
